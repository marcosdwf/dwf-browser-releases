# DWF Browser — Releases

Instaladores públicos do **DWF Browser**, o navegador desktop dedicado ao sistema
DWF Sistemas.

## Download

Baixe o instalador mais recente em **[Releases](../../releases/latest)** — o
arquivo `DWF Browser_x.y.z_x64-setup.exe`. É uma instalação por usuário (não exige
administrador). O próprio navegador se mantém atualizado automaticamente.

## Funcionalidades

Veja **[FEATURES.md](FEATURES.md)** para a lista completa de recursos.

## Requisitos

- Windows 10/11 (64 bits)
- Runtime do WebView2 (já presente na maioria dos Windows; o instalador resolve
  quando necessário)
